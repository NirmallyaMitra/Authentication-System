# Authentication System Using Node.js

A simple and secure JWT-based authentication system built with Node.js, Express.js, MongoDB, and JSON Web Token (JWT). The project implements user registration, login, password hashing, access tokens, refresh tokens, and protected routes using authentication middleware.
## Features

- User Registration & Login
- Password Hashing with crypto
- JWT Access Token
- Refresh Token
- Protected Routes
- Authentication Middleware
- MongoDB Database Integration
- Secure API Authentication
- Managing Sessions, Logout & Logout from all devices
- OTP Based Authentication


## Tech Stack

**Server:** Node, Express

**Database:** MongoDB

**API Clent:** Postman
## Run Locally

Clone the project

```bash
git clone https://github.com/NirmallyaMitra/Authentication-System.git
```

Go to the project directory

```bash
cd Authentication-System
```

Install dependencies

```bash
npm install
```

Start the server

```bash
npm run start
```
